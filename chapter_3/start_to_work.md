# 开始工作

有句老话说得好，“为自己上班，只工作，不上班”。在远古时代这也许行得通，毕竟整个原始森林就你一个人。

一旦人变多了，事情就变多了。如果世界上只有你一个人，就不会有社会问题。

通过劳动照顾好自己先，然后再考虑其他人、其他事。

# 什么是邪恶？什么是罪恶？

> once there has a person who wants to use other person as tool, take others resources, evil get created.

一旦有人想把他人当成工具使用，一旦有人想要侵吞夺取骗取他人的资源，邪恶就产生了。

举个例子，植物只吸收光和热，不想利用他人，所以是善良的。狼与猎人与强盗，想通过直接夺取他人的营养与财富变得更舒适，所以是邪恶的。养殖主与奴隶主与资本家与独裁者，想利用他人，让别人给他干活取得物质与精神财富，所以是邪恶的。

如果世界上所有植物与动物，都只吸收太阳能，那罪恶的种子就消失了，演变为天空争夺战。要突破这个局面，有2种方法。

方案1: "零生育"。每人占据1万平方米的自由土地。永生。(现在没有分得那么细致与精准与优雅，但国家与国家之间的僵持和平，现在还能维持)

方案2: 一个中心人工智能掌控全世界，没有其他物种。自己不会把自己当成工具使唤。自己也不会抢占自己的生存空间。
